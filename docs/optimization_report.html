4. 遗留事项与后续建议

  1. 全量数据集重建：修复后建议用 only_cwe 逐类构建全部 77 种缺陷并重新训练，以获得完整检测能力（当前官方权重来自旧管线，训练数据不含 B17/B18 修复后的产物差异）。
  2. 检测性能：CPU 上 246 切片约 4 分钟（官方模型 greedy 解码逐切片前向）。建议 GPU 推理或批处理优化；README 已注明算力门槛。
  3. 编译性能：每文件一次 vcvarsall 初始化（约 2s/文件）。曾尝试预导出环境变量优化但触发 WinError 87，已回退保正确性；后续可用 cmd /c set 解析结果清洗后重试，或在 CI 中一次性初始化。
  4. B11 收敛：小规模验证误报 24%，建议扩充良性样本库（多种正常程序 -rsd 收集）并平衡正负样本比例后全量训练。
  5. 配置校验：config.yaml 尚无 schema 校验，建议接入 pydantic/cerberus 在启动时校验路径与版本。
  6. CI：建议增加 GitHub Actions（Windows runner）跑 pytest 与构建冒烟。
