1. 项目简介与原理

BVSC（Binary Vulnerability detection System Combined）是论文《Binary vulnerability detection based on deep learning combined with inline assembly comparison》的工程实现，通过以下两条核心技术解决二进制漏洞检测的两个痛点：

技术解决的问题做法
① 内联汇编差异比较缺陷定位粒度粗在缺陷源码处插入内联汇编标识（nop;jmp;nop 掩码），编译后反汇编定位掩码区间，提取包含数据流的缺陷切片
② 缺陷模板扩展缺陷样本少变量/常量替换为 !!variable_i!/!!digit_i! 构成模板，随机实例化批量扩样

检测流程：待检二进制 → 反汇编 → 切片 → Transformer 模型识别 →（可选）大模型研判

3. 数据集构建

构建管线共六步，将 Juliet 缺陷样例转换为「缺陷汇编切片数据集」：

阶段说明产物目录（data/temp/ 下）
① Juliet 精简提取缺陷/修复独立源文件，去除双环境宏pretreatment/
② 内联汇编插入缺陷标识 nop/jmp 掩码windowsourcefile_inline_template/
③ 缺陷模板生成变量/常量替换为特殊字段windowsource_file_template/
④ 样本扩展模板随机实例化（默认每模板 20 个）windowsource_file_instantiation/
⑤ MSVC 编译编译为 32 位 PE 可执行文件windowsource_VUL_exefile/
⑥ 切片提取反汇编 + 掩码定位提取缺陷切片windowsource_VUL_slicingcode/

3.1 一键构建全部缺陷类型

python scripts/build_dataset.py

产物汇总至 data/total_defect_slicing.txt，每行格式：汇编切片<TAB>CWE类型。

3.2 只构建单一缺陷类型（推荐用于快速验证）

在 config/config.yaml 中设置 dataset.only_cwe，六步管线只处理该类型（juliet_testcases_dir 始终指向 .../C/testcases 根目录）：

# config/config.yaml
dataset:
  only_cwe: CWE121_Stack_Based_Buffer_Overflow   # 置空(null)则构建全部

python scripts/build_dataset.py
💡 编译阶段带实时进度展示：进度条按源文件总数推进（如 3/620），并逐文件输出日志 [编译 3/620] ✓ xxx.c 成功(4.2s)；失败详情记录在 data/temp/fild_compilation_cfile.txt。
💡 可用 python scripts/dateset_overview.py <缺陷exe根目录> 统计已构建数据集的缺陷类型/个数/成因种类。

3.3 构建产物与参数

4. 模型训练

4.1 基本训练

python scripts/train_model.py

流程：原始切片 → 模型格式数据 → 词表构建 → 训练/测试划分 → Transformer 训练 → 保存权重。

4.2 常用参数

参数说明默认
-data, --data缺陷切片集合文件（每行: 切片<TAB>CWE类型）data/total_defect_slicing.txt
-benign, --benign良性切片负样本文件（每行: 切片<TAB>NO_VULN）无
-epochs, --epochs训练轮数（覆盖配置）6（配置）
-config, --config配置文件路径config/config.yaml

4.3 合并良性负样本（强烈推荐，显著降低误报）

⚠️ 背景：仅用缺陷样本训练时，模型对良性代码也会输出某一 CWE（100% 误报）。必须加入 NO_VULN 负样本训练，模型才能学会判别「无漏洞」。
1
用 -rsd 对一批正常程序做检测，收集安全切片（自动带 NO_VULN 标签）：
python BVSC.py -efdp ./normal_bin_folder -rsd
2
训练时用 -benign 合并负样本：
python scripts/train_model.py \
    -data data/total_defect_slicing.txt \
    -benign DefectDiscoveryTrainDate/xxx_secure.txt

4.4 训练超参数（config.yaml → training）

参数默认说明
epochs6训练轮数
batch_size15批大小
learning_rate0.008SGD 学习率
momentum0.75SGD 动量
train_ratio0.95训练集占比
seed42随机种子（可复现）
💡 训练过程带实时进度条（epoch 内 batch 进度 + loss/acc 指标），完成后输出汇总统计（总准确率/平均 loss/耗时/模型路径）。CPU 上 10 万条切片 × 6 epochs 需数天，建议 GPU 训练；快速验证可用小数据集 + 少 epochs。

5. 漏洞检测工具

5.1 快速开始

python BVSC.py -efp target.exe              # 检测单个 PE 文件（顶部展示彩色 Banner）
python BVSC.py -efdp ./bin_folder           # 批量检测文件夹内全部 .exe
python BVSC.py -h                             # 查看分组帮助页（绿色主题）
🎨 CLI 美化：启动展示 dirfinder 风格彩色 Banner（红色 Logo + 版本 + 仓库信息）； 帮助页为绿色分组排版（Description / Input / Scan Modes / Output / Other / Examples）。

5.2 参数详解

参数说明默认
-efp, --exefile-path待检测二进制文件路径（PE 格式）-
-efdp, --exefile-folder-path待检测二进制文件夹（批量检测全部 .exe）-
-nrsc / --no-normal-scan普通扫描（仅本地 Transformer 模型）；--no-normal-scan 关闭开启
-acsc / --no-accurate-scan精确扫描：DeepSeek 大模型研判降噪（需配置 DEEPSEEK_API_KEY）关闭
-rsd / --no-record-secure记录判定为安全的反汇编切片（带 NO_VULN 标签，供再训练）关闭
-silent, --silent静默模式：stdout 仅输出命中行（日志走 stderr，适合管道）关闭
-json, --jsonJSON 结构化输出关闭
-o, --output结果输出文件（与 stdout 同时输出）-
-config, --config配置文件路径config/config.yaml
-v, --verbose详细模式（DEBUG 日志）关闭
-version, --version显示版本号并退出-

5.3 输出格式

默认（人类可读）

[*] C:\target.exe  切片总数=246 确认缺陷=3
    slice#12  CWE416_Use_After_Free
    slice#45  CWE761_Free_Pointer_Not_at_Start_of_Buffer

静默 + JSON（脚本消费）

python BVSC.py -efp target.exe -json -silent > hits.json
# hits.json 结构：target_file / detect_time / total_slices / defect_count / defects[]

检测报告落盘（自动生成）

每次检测在 output/ 目录生成 <文件名>_result.txt（文本）与 <文件名>_result.json（结构化）。

5.4 精确扫描（大模型研判）

本地模型输出候选后，由 DeepSeek 分析汇编代码确认漏洞真实性，过滤误报：

export DEEPSEEK_API_KEY=sk-xxxx
python BVSC.py -efp target.exe -acsc
💡 未配置 Key 时 -acsc 会警告并退回普通扫描，不会中断。

5.5 退出码

码含义
0检测完成（无论是否发现漏洞）
1参数 / 配置 / 运行依赖错误
2检测执行异常

8. 常见问题 FAQ

问题解答
检测报「模型权重加载失败」确认 models/transformer.pth 存在且与代码架构匹配（官方自带权重已匹配）；torch 1.8~2.x 均兼容。
检测良性程序误报多训练数据无良性负样本所致。按 4.3 节用 -rsd 收集安全切片 + -benign 重新训练。
数据集构建编译全部失败确认 vcvarsall_path 指向本机 VS（2019+）；必须在 Windows 环境构建。
只检测 .exe 报「无法解析 PE」工具仅支持 x86/32 位 PE 格式；64 位/Linux ELF 需另行训练对应平台模型。
-acsc 无效果需设置环境变量 DEEPSEEK_API_KEY（export DEEPSEEK_API_KEY=sk-xxx）。
训练很慢CPU 训练 10 万切片需数天；建议 GPU、减小 epochs、或先构建单缺陷类型小数据集验证。
pytest 报模块找不到本项目已配置 pythonpath=["src"]，直接在项目根目录运行即可。
